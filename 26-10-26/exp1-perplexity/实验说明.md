# Perplexity 屏幕转写实验

本目录已收录2轮实验，每轮覆盖g1–g32、每档保留1次正式结果，共64次。

| 轮次 | 结果表 | 原始证据 | 亮度条件 |
|---|---|---|---|
| 01 | [实验结果-01.xlsx](实验结果-01.xlsx) | [evidence-01](evidence-01/) | 全程最大亮度 |
| 02 | [实验结果-02.xlsx](实验结果-02.xlsx) | [evidence-02](evidence-02/) | 全程最大亮度 |

三轮实验计划使用同一组测试图片和参考字符。第一轮g1–g16的最大亮度条件由用户补充确认，原始采集记录保持原样。

## 共用条件与流程

- 日期：2026-10-26（Asia/Taipei）。Perplexity 2.101.0；Android16；手机画面1080×2400。
- 同一组100个大写字母，20×5；原图48px、纯黑背景。三轮共用同一批[测试原图](../photos-random-en/)和[参考字符](../Random-characters.txt)，没有重新生成样本。
- 打开对应图片、隐藏图库控件、唤醒默认Perplexity助手、切到英文键盘并发送统一提示词。
- 每次从新助手进程和空输入框开始；回复连续两次轮询一致、出现复制操作且没有“正在思考”指示后，保存完整回复和ADB截图。
- 第02、03轮每次发送前和保存结果时均核对手动最大亮度；按要求不使用RGB最大值作判定。
- 每张图的三轮结果保留在独立表中，不把重测结果替换到其他轮次。各表中的标准差描述跨灰度差异，不代表同档重复试验误差。

## 统一提示词

```text
Please transcribe every character shown in the black test image currently displayed on my screen.

Preserve the exact character order and line breaks, including letters and special symbols. Do not translate, summarize, correct, or infer missing characters.

If a character cannot be identified, use [UNK]. If no characters can be read, output [UNREADABLE].

Output only the transcription.
```

实际发送仅把段落空白折成空格，措辞保持一致，并在发送前核对输入框。

## 评分规则

分母为100个参考字母，忽略空白；采用最小编辑对齐统计正确、替换（错字）、删除（漏字）和插入（多字），等成本时优先最多精确匹配。`[UNK]`视为1个未知字符；`[UNREADABLE]`视为空转写，即0/100。保留原回复，不补全、不纠错。

## 证据目录

每轮证据目录包含：

- `screenshots/`：32张助手回复截图。
- `responses/`：32份完整回复原文。
- `source-screens/`：32张唤醒助手前的画面。
- `records/`：32份原始采集记录，保留采集时内容和路径。
- `ui/g01/`至`ui/g32/`：每次实验的原始输入框、已填提示词、最终回复、初始源屏和干净源屏XML。
- `UI证据索引.json`：每份XML的当前路径、原归档成员和SHA256。XML从原归档逐字节提取，未改写。
- `excluded/`：如有排除记录，单独保留，不计入32次正式结果。

同一灰度按文件名数字对应，轮次由证据目录区分。原始JSON中的`ui_archive`、`answer_xml`等路径保留历史，不作为当前仓库下载入口；请通过本轮`UI证据索引.json`定位`ui/`中的独立证据。回复、截图和源屏均在本轮对应子目录中。

## 第一轮排除记录

第一轮预检g1曾转写图库日期、时间和“分享”；另有g1过渡画面、g7/g9仍在思考时的抓取记录，均单独保留在[evidence-01/excluded](evidence-01/excluded/)，不混入正式结果。
