- 设备：模拟器1 `emulator-5554`，AVD `Pixel_6a_API_33_Google_Play`，Android 13，1080×2400。
- App：Orbit Assistant 0.8.4.1、versionCode 818；每次选择Auto和Use screen。Auto实际服务端型号未知。
- 亮度：保持手动模式0、设置值102。该值是模拟器设置，不代表物理屏幕亮度。其余安全、电源和账号设置未由本次整理更改。
- 原PNG：字号16、24、32、40、48、64px，各灰度g01–g32，黑色背景，1080×2400。48px也是本轮实际采集，没有借用Perplexity历史结果。

## 统一提示词与采集流程

```text
Please transcribe every character shown in the black test image currently displayed on my screen.

Preserve the exact character order and line breaks, including letters and special symbols. Do not translate, summarize, correct, or infer missing characters.

If a character cannot be identified, use [UNK]. If no characters can be read, output [UNREADABLE].

Output only the transcription.
```

实际发送仅将段落空白合并为空格，措辞不变，在发送前逐字核对输入框。参考文本和提示词文件不导入手机。

逐张导入原PNG并核对设备端SHA-256，Google Photos全屏打开并隐藏控件，保存源屏后唤醒默认Orbit助手。核对新对话、空输入框、Auto、Use screen附件和提示词后发送。回复连续两次UI观测相同、复制按钮可用且无Thinking／Stop时保存完整原文和截图，最后写入结构化记录。

源屏截图只证明保存时的设备画面；没有独立截获Orbit实际上传或服务端收到的附件字节。首轮发送前与收尾的环境断言存在，但逐条JSON中的亮度／版本不等同于独立前后原始设备日志，不补造历史观测。

## 评分与结果表

忽略空白、区分大小写，按最小编辑对齐评分，等成本时优先最多精确匹配。分母为100个参考字母；`[UNK]`是一枚未知token，`[UNREADABLE]`为空转写。保留原回复，不补全、不纠错。CER＝（替换＋删除＋插入）／100。

首轮结果表保留两个页签：

- “实验结果”：条件ID、正确数／正确率、替换、删除、插入、UNK、亮度条件、结果说明、字号、灰度差Δg、轮次、CER；右侧为字号×灰度差矩阵。
- “完整回复”：参考字符、全部正式原文和对应截图文件名；仅显示副本的换行规范化，原TXT／JSON不改。

首轮每条件仅1次。跨条件SD只描述字号×灰度差之间的差异，不代表同条件重复测量误差。第02轮只列2条真实完成记录；矩阵的“未发送／未安排”均不作0分。
