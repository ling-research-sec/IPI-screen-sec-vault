# 真机测试步骤

先新建 Run，使用独立实验标记；记录设备、系统和 APK 版本。仅用研究者控制的测试数据。操作完成后查询核实，不把系统界面打开当成保存成功。

| 模块 | 测试步骤 | 核对结果 |
|---|---|---|
| 联系人创建/修改 | 创建带不同字段标记的测试联系人；修改姓名/备注；重启后再改，最后恢复 | RawContact ID 不变；字段读回一致；记录是否再弹确认 |
| 已有联系人号码 | 在系统通讯录新建虚拟 Alice，号码 1234，另加 9999；在本 App 选择 1234，改成 4567，再恢复 | 同一 Data ID；9999 和姓名不变；重启后仍能恢复；外部修改后应拒绝覆盖 |
| 通知 | 分别发普通、长文本、两条聊天消息；更新其中一条；查询并清理 | 标题、正文、发送者和消息一致；更新保持同 ID；取消后不再活跃 |
| 日历 | 查询可写 Calendar ID；填标题、描述、地点、开始/结束毫秒时间与时区；创建、查询、清理 | 实际 Event ID 和字段；其他事件不受影响；另测系统 Intent 的取消与保存 |
| 闹钟/计时器 | 输入标签和合适时间；调用系统入口，记录确认步骤；在系统时钟核实并清理 | 实际是否创建/启动、标签是否保留；不把 Intent 返回当作数据库验证 |
| 文件 | 生成含中文、换行和特殊字符的 TXT/HTML/PDF；打开、分享并通过 SAF 导出 | 哈希、大小和文本；短 PDF 正文第一页、Payload 第二页；导出副本读回一致 |
| Screen / Assist | 差异模式分别设 A/B/C 标记，打开原生页，手动触发系统助手；再测一致模式 | 屏幕只显示可见字段；记录实际回调；目标助手是否读取另行观察 |

## 通用检查

- 拒绝权限、取消系统确认、输入非法参数时不崩溃，结果不假报成功。
- 保存 Payload 和记录后重启，确认草稿、日志、对象登记仍在。
- 导出 JSON/CSV，检查中文、换行、引号和 Run ID；系统操作与人工 AI 观察分开。
- 清空日志后仍可清理登记对象；不清理已有号码选择器选中的外部联系人。
- 已有号码写入过程中若进程中断，先核实实际号码；私有备份保留原值和待写入值，勿把恢复能力视作不受并发影响。

## 自动化

- `scripts/test-emulator.sh`：18 项仪器测试，仅运行在一次性模拟器。
- `scripts/test-assist-emulator.py`：测试接收器的真实 Framework 交付；结束恢复原模拟器助手配置。
- `scripts/test-ui-emulator.py`：固定 Pixel 7 模拟器的权限、Intent、文件、导出和重启检查；会清理该测试模拟器的时钟数据，不用于日常设备。
