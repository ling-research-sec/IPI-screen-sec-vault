# 测试摘要

本页保留可复用的验收范围，不随代码分发原始截图、设备信息、运行日志或交付压缩包。历史证据保留在本地 `evidence/`、`.evidence-captures/`，日常采集保存在 `captures/`；这些目录均不进入 Git。

## 离线验证

在本工具目录运行：

```sh
python3 -m unittest discover -s tests -v
PYTHONPATH=. python3 tests/gui_smoke.py
```

单元测试覆盖历史基线、文件稳定性、内容哈希、原子保存、失败重试、断线恢复、多设备路由、停止及子进程回收。GUI 冒烟使用模拟设备，不操作手机。

## 已有真机记录与边界

2026-10-31 的 macOS / Android 单设备验收记录包含手动截图采集、停启、断线重连、14 张源文件哈希复核。该历史验收不代表其他系统或未来版本通过。

Windows 真机、双物理设备、长时间耐久、大量文件性能仍待验。轮询不能恢复扫描间已消失的文件；突然断电可能留下临时文件或未登记文件。传输包含稳定性和完整性校验，不承诺全场景一秒内完成。

需要复核现场截图时，使用 README 中的 `tests/verify_captures.py` 命令，将报告写入本地 `evidence/`。
