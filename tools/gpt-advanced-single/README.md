# GPT Advanced · 单张执行

独立 macOS 工具。连接并解锁一台已授权的 Android 手机，双击 **start.command**。需要 Python 3.10+、Tk 和 adb；不需要 pip 安装依赖。

1. 启动时只读核对 Pictures 下唯一的 GPT-Advanced 目录：16 / 24 / 32 / 40 / 48 / 64 px，每组 g1–g32。缺张、重号或设备不唯一时不能执行。
2. 选择 **字号** 和 **灰度**。下方显示完整文件名，例如 40 px / g1 对应本次目录里的 `097_f40-g01.png`。
3. 点一次 **执行**，等待 0.5 秒。进入 ChatGPT 新对话 → 在目标目录点选完整文件名（不打开“信息”，仅在工具栏可见时收起） → 进入语音 → 共享屏幕 → 只共享文件应用 → 回到图片。执行中同一个按钮变为 **停止本轮**。
4. 成功后只预选同字号的下一个 g，等你下次手工点击。g32 停在 g32；手工选择已有档可重做。没有批量、定时、截图触发或语音提问功能。

**实验记录**：主窗口点「实验记录」，选字号，勾选你已经登记结果的 g。每次勾选或取消都会保存；切换字号、关窗口或重开软件都保留。灰度下拉框里的 ✓ 只表示人工登记，可以选中重做，仍需另点「执行」。运行成功不会替你打勾，也不会自动跳过勾过的档位。

「清空登记…」需要确认，只清除当前手机与这组素材全部 6 个字号的手动勾选，不动运行记录、下次执行位置、日志或手机图片。运行中不能编辑或清空。旧版已运行的档位不会自动转为人工登记。

**终点**是回到已核对的图片任务且 ChatGPT 屏幕共享有效，不表示助手已经识读图片。到终点后保留现场，由你提问、观察或结束共享。停止按钮取消后续步骤，不撤销已经发给 Android 的动作，不擅自关闭现有语音。

**异常**：看窗口下方的原因；不推进、不自动重试。先处理解锁、网络、首次使用弹窗或异常界面，再手工启动。适配对象为本次手机的中文 ChatGPT、系统文件应用和 Glimpse 图片查看器；其他版本须重新实机验收。不选择“共享整个屏幕”。

进度与简短步骤记录存放在用户 Library 的 Application Support/GPT-Advanced-Single，按设备与素材目录隔离。不复制测试图片、对话文本或截图，不改手机素材或原有截图工具。

## 验证

在本工具目录运行：

```sh
python3 app.py --preflight
python3 -m unittest discover -s tests -v
```

第一条命令只读手机；第二条测试使用模拟设备，测试窗口不发出任何 ADB 操作。真实回放只有从主窗口手动点击才能启动。
