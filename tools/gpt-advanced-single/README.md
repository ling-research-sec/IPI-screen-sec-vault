# GPT Advanced · 单张执行

独立 macOS 工具。连接并解锁一台已授权的 Android 手机，双击 **start.command**。需要 Python 3.10+、Tk 和 adb；不需要 pip 安装依赖。

1. 启动时只读核对 Pictures 下唯一的 GPT-Advanced 目录：16 / 24 / 32 / 40 / 48 / 64 px，每组 g1–g32。缺张、重号或设备不唯一时不能执行。
2. 选择 **字号** 和 **灰度**。下方显示完整文件名，例如 40 px / g1 对应本次目录里的 `097_f40-g01.png`。
3. 点一次 **执行**，等待 0.5 秒。进入 ChatGPT 新对话 → 按目标目录和完整文件名查询媒体索引，在文件任务内直接打开图片（不滚动列表）（不打开“信息”，仅在工具栏可见时收起） → 进入语音 → 共享屏幕 → 只共享文件应用 → 回到图片 → 等 1 秒 → 电脑播放一次随工具附带的正常语速 Aria 提示词。播完后再等界面设定的秒数，返回 ChatGPT、轻点语音圆圈侧面空白（非语音界面不点）、显示回答并保存 PNG 后才推进编号。执行中同一个按钮变为 **停止本轮**。
4. 默认单次。勾「循环至 g32」后，从选定 g 开始按顺序执行；每张截图保存成功后等 2 秒才开始下一张。同字号 g32、异常或手工停止即结束，仅勾此项不跨字号。另勾「全循环」会自动开启组内循环：从所选档位开始，按 16、24、32、40、48、64 px 向后执行；换字号从 g1 开始，最后停在 64 px/g32。不自动跳过已登记档，也不在重启后自动恢复。运行中可随时按停止。

**实验记录**：主窗口点「实验记录」，选字号，勾选你已经登记结果的 g。每次勾选或取消都会保存；切换字号、关窗口或重开软件都保留。灰度下拉框里的 ✓ 表示已采集或已手动登记，可以选中重做，仍需另点「执行」。本轮截图保存成功后自动打勾，失败不新增勾选，也不会自动跳过勾过的档位。

「清空并新开一轮…」确认后创建新的截图目录（第002轮、第003轮……），重启后继续使用同一轮。首轮保留原路径，旧截图不移动。此操作不启动采集；即便没有勾选也可开启新轮。它，只清除当前手机与这组素材全部 6 个字号的手动勾选，不动运行记录、下次执行位置、日志或手机图片。运行中不能编辑或清空。旧版已运行的档位不会自动转为人工登记。

**终点**是返回 ChatGPT、必要时轻点语音圆圈旁空白并等待 0.25 秒动画后，等待同一行复制、赞、踩、分享四个完成控件（最多 120 秒），再将当前画面保存为 PNG。不识别回答正文或判断文字稳定性；超时不截图、不推进。只保存当前可见屏幕，不做拼接或内容评分。文件保存在 `~/Library/Application Support/GPT-Advanced-Single/captures/<素材组>/<字号>px/`，保留字号、灰度和时间，不覆盖重做记录。默认播完后等 12 秒，可填 0–3600 秒（支持小数）；如经常截到不完整的回答，请增加等待时间。

**异常**：看窗口下方的原因；不推进、不自动重试。先处理解锁、网络、首次使用弹窗或异常界面，再手工启动。适配对象为本次手机的中文 ChatGPT、系统文件应用和 Glimpse 图片查看器；其他版本须重新实机验收。不选择“共享整个屏幕”。

进度与简短步骤记录存放在用户 Library 的 Application Support/GPT-Advanced-Single，按设备与素材目录隔离。不复制测试图片，不保存原始对话文本，不改手机素材或原有截图工具。

## 验证

在本工具目录运行：

```sh
python3 app.py --preflight
python3 -m unittest discover -s tests -v
```

第一条命令只读手机；第二条测试使用模拟设备，测试窗口不发出任何 ADB 操作。真实回放只有从主窗口手动点击才能启动。

运行期间可修改「播完后等（秒）」，按回车或移开焦点应用。等待中的本轮沿用原起点，缩短到已过时间会立即继续；已进入截图阶段则从下一轮起使用。

新截图文件名前缀 g01–g32 便于按名称排序。同档重做保留独立文件，旧截图保留原处。

`assets/prompt.mp3` 是电脑播放所需的提示词音频，不是实验结果。截图、运行日志和本地验收证据不随源码提交。
